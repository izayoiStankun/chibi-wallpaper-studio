# 작은 화면 공방

기존 Grokbot 아이콘과 원본 이미지가 있는 대화에서 이어 쓰는 치비·월페이퍼 프롬프트 안내 페이지.

## 현재 상태

**원작자 공개 허락 수령(사용자 확인). 다국어 수정본 최종 검토 중이며 GitHub Pages 공개 배포는 아직 설정하지 않음.**

사용자가 원작자에게 긍정적인 허락을 받았다고 알려주었습니다. 수정본을 직접 확인한 뒤 본 배포로 전환할 예정입니다.

페이지 제작자: [X @Stang_kun](https://x.com/Stang_kun). 원작 프롬프트 저작자는 아래에 별도로 표기합니다.

## 단일 콘텐츠 원본

`master-prompt.txt`는 작업 시점의 `배포용_치비_월페이퍼_마스터프롬프트.txt`를 그대로 복사한 파일입니다. 홈페이지는 이 파일을 읽어 최종 `[휴대폰 기종]` 다음의 안내 한 줄만 사용자의 입력값으로 바꿉니다. 다른 프롬프트나 과거 버전을 합치지 않습니다.

홈페이지의 휴대폰 일러스트는 화면 구성 설명용으로 직접 작성한 SVG/CSS이며 실제 생성 결과를 나타내지 않습니다. 캐릭터 원본, 기존 생성 이미지, 원작 사이트의 디자인·이미지·소스코드는 사용하지 않았습니다.

## 언어

한국어(원문), 영어, 일본어, 중국어 간체, 중국어 번체를 제공합니다. `locales.js`는 페이지 문구 및 접근성 안내를, `prompt-en.txt`, `prompt-ja.txt`, `prompt-zh-Hans.txt`, `prompt-zh-Hant.txt`는 원문에서 번역한 전체 프롬프트를 담습니다. 새 지침을 추가하거나 기존 규칙을 생략하지 않았습니다. 번역은 AI가 작성했으며 전문 번역가의 감수를 받은 것은 아닙니다.

언어를 바꾸면 전체 프롬프트·복사·다운로드도 함께 바뀝니다. 사용자가 적은 기종은 그대로 유지합니다. 기종 외의 본문은 언어별 원문을 보존합니다. 주소의 `?lang=en`, `?lang=ja`, `?lang=zh-Hans`, `?lang=zh-Hant`로 해당 언어를 바로 열 수 있습니다. 언어 로딩 중에는 이전 언어의 프롬프트가 복사되지 않도록 버튼이 비활성화됩니다.

## 로컬 미리보기

Node.js에서 `npm run preview` 실행 후 http://127.0.0.1:4173 접속.

`npm run check`는 검토 파일을 갱신한 뒤 5개 언어의 문구 완전성, 프롬프트 구조, 기종 삽입 시 본문 보존, 줄바꿈, 특수문자 입력, 실패 처리 및 오프라인 번들을 확인합니다. 추가 패키지 설치는 필요하지 않습니다.

`npm run review`로 만들어지는 `review.html`은 스타일·5개 언어의 전체 프롬프트·스크립트가 모두 들어 있는 단일 HTML 파일입니다. 시스템 폰트를 사용하며 서버 없이 언어를 전환할 수 있습니다. 브라우저에서 열어 검토할 수 있고, 자동 복사가 제한된 브라우저에서는 수동 복사 칸을 사용합니다. 이 파일을 만드는 것은 공개 호스팅이나 배포를 실행하지 않습니다.

## 확인 후 공개할 때

사용자의 최종 검토 후 미리보기 표기와 robots 메타 태그를 정리합니다. GitHub Pages는 저장소 루트의 정적 파일을 배포할 수 있습니다. 리소스 경로는 상대 경로로 작성되어 프로젝트 하위 주소에서도 동작합니다. 외부 폰트, 분석 도구, 이미지 업로드, 계정 정보 수집, AI API 연결은 없습니다. 기종은 브라우저 메모리에서만 사용하며 전송·저장하지 않습니다. 선택 언어만 주소에 표시하며 기종은 주소에 포함하지 않습니다.

# 작은 화면 공방

기존 Grokbot 아이콘과 원본 이미지가 있는 대화에서 이어 쓰는 치비·월페이퍼 프롬프트 안내 페이지.

## 현재 상태

**원작자 확인 전 비공개 검토본. GitHub Pages 공개 배포를 설정하지 않음.**

사용자는 원작자에게 직접 확인한 뒤 공개 여부를 결정할 예정입니다. 승인 전 저장소 공개 전환, Pages 설정 또는 자동 배포를 실행하지 않습니다.

## 단일 콘텐츠 원본

`master-prompt.txt`는 작업 시점의 `배포용_치비_월페이퍼_마스터프롬프트.txt`를 그대로 복사한 파일입니다. 홈페이지는 이 파일을 읽어 최종 `[휴대폰 기종]` 다음의 안내 한 줄만 사용자의 입력값으로 바꿉니다. 다른 프롬프트나 과거 버전을 합치지 않습니다.

홈페이지의 휴대폰 일러스트는 화면 구성 설명용으로 직접 작성한 SVG/CSS이며 실제 생성 결과를 나타내지 않습니다. 캐릭터 원본, 기존 생성 이미지, 원작 사이트의 디자인·이미지·소스코드는 사용하지 않았습니다.

## 로컬 미리보기

Node.js에서 `npm run preview` 실행 후 http://127.0.0.1:4173 접속.

`npm run check`는 기종 삽입 시 원본 보존, 줄바꿈, 특수문자 입력과 실패 처리를 확인합니다. 추가 패키지 설치는 필요하지 않습니다.

`npm run review`로 만들어지는 `review.html`은 폰트·스타일·프롬프트·스크립트가 모두 들어 있는 단일 HTML 파일입니다. 원작자에게 직접 전달해 브라우저에서 열어볼 수 있습니다. 자동 복사가 제한된 브라우저에서는 수동 복사 칸을 사용합니다. 이 파일을 만드는 것은 공개 호스팅이나 배포를 실행하지 않습니다.

## 확인 후 공개할 때

공개 허락 및 표시 문구를 확인한 뒤 미리보기 표기와 robots 메타 태그를 검토합니다. GitHub Pages는 저장소 루트의 정적 파일을 배포할 수 있습니다. 리소스 경로는 상대 경로로 작성되어 프로젝트 하위 주소에서도 동작합니다. 외부 폰트, 분석 도구, 이미지 업로드, 계정 정보 수집, AI API 연결은 없습니다. 기종은 브라우저 메모리에서만 사용하며 전송·저장하지 않습니다.

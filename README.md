# 작은 화면 공방 · Chibi Wallpaper Studio

**마음에 드는 아이콘에서, 내 휴대폰을 위한 작은 풍경까지.**

작은 화면 공방은 완성된 Grokbot 아이콘을 **2.5등신 전신 치비 캐릭터와 휴대폰 월페이퍼**로 이어가는 프롬프트를 준비해주는 웹사이트입니다. 휴대폰 기종을 입력하고 원하는 언어를 선택하면, 같은 ChatGPT 대화에서 이어 쓸 전체 프롬프트를 복사하거나 텍스트 파일로 내려받을 수 있습니다.

**[홈페이지 바로가기 →](https://izayoistankun.github.io/chibi-wallpaper-studio/)**

## 사용 방법

1. **아이콘 준비** — ChatGPT 대화에 캐릭터 원본 이미지를 올리고, [Grokbot Icon 페이지](https://grokbot-icon-studio.serio-ai.chatgpt.site/)의 프롬프트로 아이콘을 먼저 만듭니다.
2. **언어와 기종 선택** — [작은 화면 공방](https://izayoistankun.github.io/chibi-wallpaper-studio/)에서 언어를 선택하고 정확한 휴대폰 모델명을 입력합니다. 예: `갤럭시 S24 FE`.
3. **프롬프트 복사** — 기종이 반영된 프롬프트를 복사합니다. 텍스트 파일로 내려받을 수도 있습니다.
4. **같은 대화에서 이어가기** — 아이콘과 원본 이미지가 있는 ChatGPT 대화에 붙여넣습니다. 프롬프트가 전신 치비 제작과 잠금 화면 월페이퍼 제작을 순서대로 요청합니다.

원본 이미지는 의상·신발·고유 장식을, 완성된 아이콘은 얼굴과 채색을 참고하는 데 사용합니다. 실제 이미지 제작은 ChatGPT 대화에서 진행합니다.

## 프롬프트에 담긴 내용

- **약 2.5등신의 전신 치비** — 둥근 얼굴과 검은 캡슐 눈을 유지하고, 머리 장식부터 신발까지 화면 안에 담습니다.
- **캐릭터와 어울리는 풍경** — 의상·색상·장식을 참고해 장면을 정하고, 부드러운 플랫 2D 배경으로 연결합니다.
- **잠금 화면을 위한 여백** — 시계와 알림 공간, 화면 가장자리에서 캐릭터가 잘리지 않도록 하는 안전 여백을 요청합니다.
- **기종에 맞는 화면 구성** — 제조사 공식 사양과 최종 파일의 실제 픽셀 크기를 확인하도록 요청합니다. 정확한 해상도로 내보낼 수 없다면 실제 출력 크기를 알리도록 합니다.
- **폴더블 지원** — 커버 화면과 안쪽 화면에 맞는 월페이퍼를 각각 요청합니다. 기종과 함께 특정 화면을 적으면 그 화면만 요청합니다.

홈페이지의 휴대폰 그림은 구성을 설명하기 위한 일러스트입니다. 실제 결과는 참고 이미지와 사용하는 이미지 생성 도구에 따라 달라집니다.

## 입력 정보

휴대폰 기종은 브라우저 메모리에서만 사용하며 서버로 전송하거나 저장하지 않습니다. 공유 주소에는 선택 언어만 표시됩니다. 이미지는 원래 사용하던 ChatGPT 대화에 올려주세요. 이 사이트에는 이미지 업로드, 계정 정보 수집, 분석 도구 또는 AI API 연결이 없습니다.

## 개발 및 배포

HTML·CSS·JavaScript로 구성된 정적 사이트이며 별도 패키지 설치 없이 실행할 수 있습니다. GitHub Pages가 `main` 브랜치의 저장소 루트를 배포합니다.

```sh
npm run preview  # 로컬 미리보기: http://127.0.0.1:4173
npm run check    # 번역 문구, 프롬프트 본문 보존, 기종 삽입과 오프라인 번들 확인
npm run review   # 서버 없이 열 수 있는 단일 HTML 파일 생성
```

한국어 프롬프트는 `master-prompt.txt`, 번역 프롬프트는 `prompt-en.txt`, `prompt-ja.txt`, `prompt-zh-Hans.txt`, `prompt-zh-Hant.txt`에 있습니다. 페이지는 선택한 언어의 본문을 유지하면서 마지막 기종 안내만 입력값으로 바꿉니다.
